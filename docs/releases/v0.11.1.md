# v0.11.1

## Highlights

- **Fix `resend` pane address validation:** `hrelay resend` previously failed with "invalid core terminal address for direct send" when the stored pane was a full session address (`t7p@1795549294511:13380:13380`). `SendDirect` now accepts both the short terminal-ID format (`t<id>`) and the full session-address format (`t<id>@<session>`).

## Upgrade and compatibility

1. CLI-only fix. No schema migration or daemon restart required.
2. Update the CLI binary with `herdr plugin install avery20024/herdr-async-message-relay --yes` or `hrelay cli install` after rebuilding.

See [v0.11.0 notes](v0.11.0.md).
