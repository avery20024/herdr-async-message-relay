# v0.8.1

## 修正：暫時隱藏 Claude 問答攔截設定

- Claude 問答攔截尚不能正確運作，`hrelay ui` 的 Ctrl+P 暫時隱藏該開關及下方兩行提示。
- 偏好設定僅保留語系與主題，方向鍵／j/k 導覽與欄位計數同步改為兩項。
- 開啟、重載或儲存偏好設定不再讀寫 worker 的攔截政策；攔截 API 不可用也不影響本機偏好儲存。
- **問答紀錄功能維持不變**：沒有修改 scoped Hooks、事件記錄、worker、資料庫或攔截政策預設值。

## 升級與限制

- 隱藏開關不代表修復或停用攔截。既有明確啟用的政策仍然保留；本次修改不會自動關閉它。
- 既有 scoped Hooks 仍依原機制記錄問答。本版本不補裝 Hook、不偽造初始化狀態，也不變更記錄格式。
- 安裝新版 CLI 後須重新開啟 UI 才會看到選單變更；不需要為這項 UI 調整重啟 worker。
- 無 DB migration 或新依賴。發布、安裝與正式服務切換仍是不同操作，不因版本更新宣稱已部署。

## 驗證

- 自檢涵蓋 `make check`：Go vet／race 全套、44 項 Python（含 PTY／Hook）與建置；另檢查依賴一致性與模組完整性。
- 回歸涵蓋雙語、五主題、NO_COLOR、兩項導覽／欄位計數、既有政策 on/off 保留及偏好操作不呼叫 guard API。
- 真實 Claude 問答攔截與 Hook 端到端驗收不在本次範圍內；原有問答記錄隔離測試保持通過。

完整操作見 [UI 說明](../ui.md)。
