# v0.6.0

## 重要行為變更：團隊問答攔截預設開啟

- Claude AskUserQuestion 攔截改為團隊共用政策，缺少 `team-policy.json` 時預設開啟。**未接線或未初始化的 Claude 角色會持續延後通知**，不是沿用舊版每角色 opt-in。
- 舊 `<role>/policy.json` 保留但不再控制投遞，舊 `--role ROLE enable|disable` 明確拒絕，改用 `claude-guard --team enable|disable|status`；每角色仍可查 `--role ROLE status`。
- `Ctrl+P` 新增團隊問答攔截設定，UI 與 worker 均須支援 v0.6.0。worker 動態讀取政策；儲存回應遺失時須先重載確認，不盲目重試。
- 關閉攔截仍記錄已接線、有效 Hook 的起訖、耗時與異常，不記錄問題／答案本文；缺少完成事件不偽造結束或以逾時解鎖。Herdr 的 `blocked` 防線不因關閉而繞過。
- 每角色持久追加 `events.jsonl`，state 保留最近 20 筆摘要；日誌無自動輪替，事件與 state 非跨檔交易。未配對的工具失敗仍持久化並保守保留 unknown。

## UI 操作改善

- 垂直滾輪依滑鼠位置分派：列表選取一筆、左下資料／右下本文各捲一行。彈窗開啟時不操作背景；框線、標題、footer 及水平滾輪忽略。
- 左下兩行說明固定置底，使用淡色樣式；欄位 key 維持一般樣式，value 使用主題強調。樣式逐行結束，避免中途捲入時粗體／色彩延伸至外框。
- 新增 `gg` 跳到已載入第一筆；`G`／`Shift+g` 跳到當時已載入最後一筆，不額外載入歷史。晚到分頁可以追加資料，但不可覆蓋明確跳轉。
- `gg` 無時間期限，以連續兩次小寫 g 判定；其他按鍵、滑鼠點擊／放開／滾輪或 resize 會取消。說明視窗原本單個 g／G 的頂底導覽保留。
- 支援英／繁中、各主題、NO_COLOR、最小 20×10 畫面。最小畫面左下保留一行資料及兩行固定說明，右下仍有三行本文；資料內容完整可捲動查看。

## 升級與啟用

1. 發布、安裝 CLI、替換運行中的 worker 與 Claude Hooks 接線是不同操作；本版本不自動修改 Claude 設定、安裝全域 Hooks、重啟座位或切換服務。
2. 升級前備妥既有 pending／session／事件資料，不刪除或偽造 ready。先在隔離環境使用同版本 CLI／worker，讓真實新會話的 SessionStart 初始化角色。
3. 尚未準備 Hooks 的團隊，須明確安排是否先用新版 binary 在同一 state directory 儲存 team-off 政策，再分階段接線、驗證及啟用；這是可選的部署決策，不是隱含遷移預設。
4. 舊 worker 沒有新設定 API 時，UI 顯示設定不可用，不代為寫入猜測值。降版前須查核原問答狀態與舊版每角色政策，不能假設舊版會讀取團隊政策。
5. 沒有佇列 DB migration、新依賴或 TCP listener。

完整設定、遷移、復原及限制見 [問答觀測與團隊攔截](../claude-question-guard.md)；操作見 [UI 文件](../ui.md)。

## 驗證與已知限制

- 功能版本已通過獨立本地審核及 Ubuntu／macOS CI，涵蓋 Go race、39 項 Python／PTY 測試、依賴一致性與 sqlc 產生碼檢查；版本準備提交與正式成品仍須分別核驗。
- 本版團隊政策／UI 的真實 Claude／Herdr 問答端對端、實體滑鼠與各終端手動畫面驗收仍未完成；歷史單角色原型測試不能當作本版已驗證。
- 問答防護僅涵蓋 AskUserQuestion，不保證排除漏發／失敗 Hooks、其他授權對話框或 Herdr 快照與提交之間的競態；既有 ready 不代表 Hooks 持續健康。
- 資料欄位使用終端格寬硬換行，長單字可能中途斷行；滑鼠回報可能使原生文字選取需搭配終端的繞過修飾鍵。
- 不因發布成功宣稱正式環境已升級或防護已生效。
